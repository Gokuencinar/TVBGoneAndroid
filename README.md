# TVBGoneAndroid

Versión Android de **TV-B-Gone / IR Universal**, una aplicación para enviar códigos infrarrojos de apagado/control a televisores y otros equipos compatibles usando el emisor IR integrado del teléfono o un adaptador IR conectado por audio.

**Compatibilidad:** Android 11 o posterior (`minSdk 30`).

- Kotlin
- IR integrado mediante `ConsumerIrManager`
- Emisión mediante adaptador IR de audio estéreo
- Base TV-B-Gone Europa y Norteamérica/Asia
- Importación Flipper `.ir`
- Biblioteca IR online
- Aprendizaje IR mediante entrada de audio

La versión Android actual es **0.1.0-android**.

Consulta [CHANGELOG.md](CHANGELOG.md) para ver las novedades, cambios y correcciones de cada versión.

El proyecto procede del port desarrollado inicialmente en la rama `android-port` de
`Gokuencinar/TVBGoneAudio` y se mantiene aquí como proyecto independiente.
